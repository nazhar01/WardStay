# 🏥 WardStay

A personal hospital ward management system prototype developed as part of my software engineering learning journey through the **IBM Full Stack Developer Professional Certificate**.

---

## 📖 About

WardStay is a front-end prototype for a hospital ward management system inspired by real-world caregiving experiences.
The application was designed to organize patient information, caregiver notes, and vital signs into a simple and intuitive interface that makes essential information easier to access.
This project marks my first software project published on GitHub as part of my transition into software engineering through the IBM Full Stack Developer Professional Certificate.

---

## ✨ Features

- Patient Overview
- Caregiver Notes
- Vital Signs Dashboard
- Clean responsive interface
- Simple hospital information layout
